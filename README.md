# Рейтинг горнолыжных курортов России (Travel Designer)

**Заказчик:** Travel Designer
## Контекст
Стартап планирует создать платформу для подбора горнолыжных курортов. Для наполнения каталога при ограниченности ресурсов необходимо выбрать наиболее привлекательные для туристов и выгодные с точки зрения охвата курорты. Готовой информации и рейтингов посещаемости курортов в открытом доступе нет.

## Цели проекта
Определить, какие курорты стоит добавить в каталог в первую очередь, и проверить, насколько устойчив этот выбор.

## Бизнес-постановка
Добавление наиболее популярных курортов при ограниченности ресурсов поможет охватить наиболее широкую аудиторию пользователей.

## Задачи
1. Собрать данные из нескольких источников по факторам, которые могут влиять на рейтинг курорта.
2. Проверить качество и полноту данных, подготовить данные из каждого источника к дальнейшему анализу.
3. Построить составной рейтинг по каждому из курортов (одна цифра рейтинга для одного курорта), а также дать оценку степени уверенности в данных.
4. Проверить устойчивость рейтинга при разных сценариях оценки факторов.
5. Подготовить воспроизводимый пайплайн: любой разработчик или аналитик должен получить аналогичный рейтинг на основе готовых сырых данных.
6. Сформулировать пояснения, какие факторы и как повлияли на итоговый рейтинг курорта.
7. Сформулировать выводы и подготовить рекомендации.

## Инструменты
Python (pandas, NumPy, requests, haversine), Jupyter Notebook, Yandex DataLens, Open-Meteo API

## Результаты
- Воспроизводимый пайплайн расчетов: `src/run_pipeline.py`
- Итоговые таблицы: `mart/resort_rating_full.csv`
- Ноутбук с анализом: `notebooks/resort_ranking_analysis.ipynb`
- [Дашборд DataLens](https://datalens.yandex/7im7fv9he26kq)

## Ключевые выводы
Топ-10 наиболее популярных курортов:
1. «Сорочаны» (Московская область)
2. «Роза Хутор» (Краснодарский край)
3. «Газпром Поляна» (Краснодарский край)
4. «Красная Поляна» (Краснодарский край)
5. «Игора» (Ленинградская область)
6. «Шерегеш» (Кемеровская область)
7. «Горный воздух» (Сахалинская область)
8. «Архыз» (Карачаево-Черкесская Республика)
9. «Домбай» (Карачаево-Черкесская Республика)
10. «Бобровый лог» (Красноярский край)

После проверки устойчивости лидеров в разных сценариях весов для разных групп, можно рекомендовать следующую очередность добавления курортов в каталог:

**1**: «Сорочаны», «Роза Хутор», «Газпром Поляна», «Красная Поляна». У этих курортов высокий рейтинг и достаточно высокая уверенность в данных (75 и выше), и они устойчиво держатся наверху в разных сценариях. Для «Газпром Поляны» и «Красной Поляны» данные о снеге, вероятно, занижены: модель ERA5 с крупной сеткой сглаживает горный рельеф и недооценивает снег в горах. Поэтому их стоит добавлять при условии проверки снежных данных.

**2**: «Игора», «Шерегеш», «Горный воздух». Эти курорты занимают более низкие места в десятке, но остаются в ней при всех проверках. У «Игоры» и «Горного воздуха» низкая формальная уверенность из-за отсутствия цены и пометки справочника о координатах, но сверка подтвердила их координаты, а цена не может вывести их из топ-10. Перед подключением всех трёх курортов желательно уточнить цену ски-пасса.

**3**: «Архыз», «Домбай», «Бобровый лог». Они в топ-10 по базовому сценарию, но немного выпадают из него хотя бы в одной проверке (11–15-е места).

Для четырёх курортов из топ-10 точка справочника смещена: у «Розы Хутор» на 3,9 км, у «Красной Поляны», «Домбая» и «Горного воздуха» — на 1–2 км. Перед добавлением в каталог желательно уточнить их оценку по точным координатам.

В списке есть два закрытых курорта — «КолаСпортЛэнд» и «Аджигардак». Их нет смысла добавлять в каталог независимо от места в рейтинге.

## Как запустить
Требуется Python 3.10 или новее.
```
pip install -r requirements.txt
python src/run_pipeline.py
```
Команды выполняются из корня проекта. Пайплайн по очереди запускает `src/prepare.py` → `src/build_mart.py` → `src/scoring.py` и пересобирает `prepared/` и `mart/` из сохранённых данных `raw/`. Если любая проверка не пройдена, пайплайн останавливается с ошибкой.

Погода уже сохранена в `raw/weather/`. Чтобы скачать её заново из Open-Meteo, необходимо отдельно запустить `python src/collect_weather.py`, затем `python src/run_pipeline.py`.

Дашборд построен на снимке `mart/resort_rating_full.csv`. Чтобы обновить его, перезапустите пайплайн и замените файл в подключении DataLens.

## Источники данных
Полный перечень источников с периодами, датами сбора и описанием преобразований — в `raw/sources.csv`.
- **Погода** — собрана самостоятельно через Open-Meteo Historical API (модель ERA5, сезоны 2021/22–2025/26).
- **Справочник курортов** с объектами OSM и ближайшими аэропортами, **поездки и ночёвки Росстата** (ЕМИСС) и **цены ски-пассов** — из материалов проекта.
- **Проверка координат** — вручную по Яндекс Картам для всех 32 курортов (`raw/coordinate_checks.csv`, скриншоты в `assets/`).

## Особенности данных и ограничения
- Координаты в справочнике проекта взяты из Википедии и Wikidata, часть из них была помечена как требующая проверки. Все 32 курорта вручную сверены с Яндекс Картами (`raw/coordinate_checks.csv`): у 10 курортов точка справочника смещена от склона больше чем на 3 км. Погода, объекты OSM и расстояние до аэропорта рассчитаны по координатам справочника, поэтому для этих курортов они могут быть неточными.
- По Яндекс Картам «КолаСпортЛэнд» и «Аджигардак» не работают. Они остаются в расчёте (32 курорта по ТЗ), но исключены из рекомендаций.
- Некоторые курорты расположены ближе 6 км друг к другу, и радиусы поиска объектов OSM пересекаются: часть объектов учтена у нескольких курортов сразу. Такие курорты отмечены флагом в колонке качества данных.
- Названия двух регионов в данных Росстата отличаются от справочника курортов. Для соединения используется словарь `REGION_NAME_MAP` в `src/build_mart.py`.
- Региональный спрос взят за год и по всему региону, а не по конкретному курорту: он может включать другие виды отдыха, и у курортов одного региона он одинаковый.
- Цены на ски-пасс есть только у 9 из 32 курортов (прошлый сезон); остальные получают нейтральный балл 50.

Подробнее об ограничениях — в разделе «Выводы и рекомендации» ноутбука.

## Отклонения от ТЗ
- Погода собрана по модели ERA5, а не ERA5-Land, рекомендованной в ТЗ: при запросе к Open-Meteo модель ERA5-Land не отдаёт снегопад, без которого не посчитать снежные дни и сезонный снегопад. ERA5 — модель с крупной сеткой и, вероятно, занижает снег в горах.
- Флаг отсутствия цены называется «нет данных adult_skipass_avg_rub» вместо «missing price». Правило обработки то же: нейтральный балл 50.
- Расширенный слой Росстата (раздел 13 ТЗ, необязательный) в первой версии не выполнялся.

## Сравнение с контрольным рейтингом
Рейтинг отличается от контрольной таблицы ТЗ (Приложение Б) больше чем на 0,2 балла. Расхождение вызвано данными о снеге: собственные данные Open-Meteo (ERA5) для горных курортов заметно ниже значений справочника проекта. Если подставить в расчёт погоду из справочника, результат совпадает с Приложением Б для всех 32 курортов. Остальные формулы и данные воспроизведены без расхождений.

## Проверки в пайплайне
Пайплайн останавливается с ошибкой, если не выполнено одно из условий:
- сумма весов в каждом сценарии равна 100;
- все 13 баллов лежат в диапазоне от 0 до 100;
- в витрине строк столько же, сколько курортов в справочнике (32), все `resort_id` уникальны;
- после соединения с региональными данными нет пропусков в `trips_2025`.
